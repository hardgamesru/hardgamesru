# Andrei Baldin

**Software Engineering · Applied AI Research · Machine Learning**

My interests lie in **LLM agents, multi-agent coordination, machine learning, and reliable AI systems**. 

## Research & projects

**[Multiagent LLM Coordination](https://github.com/hardgamesru/Multiagent_LLM_Coordination)**  
An experimental framework for comparing agent-coordination graphs on programming tasks, using automated tests and metrics such as success rate, messages, token usage, and execution time. This work is linked to a 2026 conference publication.

**Adaptive Coordination for Coding Agents** ·
Investigating when a coding agent should delegate testing and review, compared with fixed single-agent and multi-agent workflows. 

**[NexTalk](https://github.com/hardgamesru/nexTalk)**  
A client-server messenger with a C++17/POSIX backend, Vue interface, SQLite storage, TLS, and a separate AI-assistance service.
